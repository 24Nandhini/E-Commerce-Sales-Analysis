# E-Commerce Sales Analysis using SQL

## Project Overview

This project analyzes e-commerce sales data using SQL to identify sales trends, customer behavior, order performance, and product performance.

## Tools & Technologies

- MySQL
- SQL
- MySQL Workbench
- Git & GitHub

## Dataset

The dataset contains information about customers, orders, products, and order items.

### Tables

- Customers — Customer details
- Orders — Order and payment details
- Products — Product details
- Order Items — Products purchased in each order

## SQL Analysis

The following SQL queries were used to analyze the data:

1. Joining multiple tables
2. Calculating total sales
3. Analyzing order status
4. Finding customer-wise sales
5. Identifying best-selling products
6. Analyzing monthly sales
7. Calculating category-wise revenue
8. Finding top 3 customers
9. Calculating average order value
10. Analyzing revenue by order status
